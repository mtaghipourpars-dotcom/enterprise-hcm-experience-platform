# Gotchas / Non-obvious rules

1. Do not treat payroll results as a simple transparent employee table.
2. Do not assume all Talent/Performance data maps to classic PA infotypes.
3. Do not assume a fixed Training/Event table list across releases.
4. Preserve SAP effective dates.
5. Preserve SAP source keys and object identity.
6. Do not expose sensitive payroll/medical/performance data merely because a user is a manager.
7. Do not use configuration files for business data.
8. A UI tile is not a security boundary.
