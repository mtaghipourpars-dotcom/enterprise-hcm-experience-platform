# Agent Skills Compliance

This package follows the public Agent Skills specification:
- skill is a directory
- `SKILL.md` is required
- YAML frontmatter requires `name` and `description`
- optional `compatibility` and `metadata` are supported
- `references/`, `scripts/`, and `assets/` are used for progressive disclosure
- validation is expected via `skills-ref validate <skill-dir>`

Source:
https://github.com/agentskills/agentskills/blob/main/docs/specification.mdx
