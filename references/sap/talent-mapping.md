# SAP Mapping — Talent & Performance

Talent/Performance mapping is explicitly release-dependent.

Required source contract:
- source product/release
- source object/API
- source key
- effective period
- field-level map
- authorization semantics

Model goals, appraisals, IDPs, career and succession in `hcm_core`, but keep the exact SAP source object in `hcm_integration.source_mapping` and do not invent SAP table names.
