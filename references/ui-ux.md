# UI/UX

The UI is a premium enterprise experience, not an SAP GUI clone.

Required views:
- Employee Experience
- Manager Experience
- Executive Workforce Intelligence

Primary demo narrative:
Executive -> Manager -> Employee -> service -> underlying real data -> return to Executive insight.

Required reusable components:
- ServiceTile
- ProfileCard
- KPI Card
- DataTable
- OrganizationTree
- RequestTimeline
- PayrollBreakdown
- QualificationGap
- GoalCard
- PerformanceCard
- TrainingBooking
- ExecutiveMetric

All visual configuration is externalized.
